# 04 · 动效菜单

用「给菜单让用户挑」的方式，而不是自己闷头加一堆动效。

---

## 十项菜单

| 编号 | 名称 | 效果 | 适合什么气质 |
| --- | --- | --- | --- |
| ① | 静态 | 任何动效都不加 | 极简、严肃、数据密集 |
| ② | 3D 装饰小元素 | 微浮雕、微缩浮动、hover 微倾斜 | 印刷、手作、卡片 |
| ③ | 双层 cursor | 自定义跟随光标 | 现代、创意工作室 |
| ④ | stagger 错位 | 一组元素按序逐个浮现（组内延迟 60–80ms） | 几乎所有风格 |
| ⑤ | letter-spacing 收束 | 标题字距从宽收窄 | 排版驱动、杂志、报纸 |
| ⑥ | odometer 滚动 | 数字从 0 滚到目标值 | 有数据的简历、成绩、指标 |
| ⑦ | 背景色过渡 | 区块进入时背景色柔和变化 | 长页面、章节叙事 |
| ⑧ | 抬起 + 投影 | hover 上浮 + 投影加深 | 卡片网格 |
| ⑨ | SVG 手写描边 | 图标笔画逐渐画出 | 手账、插画、复古 |
| ⑩ | 朴素 | 只用最基础的 fade | 极简 |

## 分档建议

| 档位 | 选几项 | 场景 |
| --- | --- | --- |
| Level 0 | ①/⑩ | 用户明确说"不要动效" |
| **Level 1 优雅档** | **4–7 项** | **默认推荐** |
| Level 2 表现档 | 8–10 项 | 用户要求"炫"，且是创意类身份 |

## 一次真实的选配（Level 1）

用户身份：新媒体运营 + 内容创作 + 严谨数据。风格：报纸印刷（法兰西特派）。

**选了 7 项**：

| 选中 | 落地 |
| --- | --- |
| ⑤ letter-spacing 收束 | Hero 刊名 & 章节标题字距从宽收窄（铅字排印感） |
| ④ stagger 错位 | 信息卡、作品卡按序逐张浮现（组内 80ms） |
| ⑥ odometer 滚动 | 实践经历 20+ 个数字滚动计数（easeOutCubic） |
| ⑦ 背景色过渡 | 章节进入时纸色→亮纸过渡（翻页感） |
| ⑧ 抬起 + 投影 | 卡片 hover 上浮 + 硬投影加深 |
| ② 3D 装饰 | 章节牌印刷浮雕、Hero 微缩菱形浮动、人像框 hover 微 3D |
| ⑨ SVG 描边 | 邮箱图标改手绘信封，笔画描边动画 |

**明确不选，并说明理由**：

- ③ 双层 cursor —— 现代 UI 语言，与报纸复古气质冲突
- ① / ⑩ —— 与"加动效"的诉求直接矛盾

> **「不选什么 + 为什么」和「选什么」一样重要。** 这说明你在做判断，不是在堆功能。

## 实现要点（零库，纯原生）

### stagger

```css
.stagger > * { opacity: 0; transform: translateY(12px); }
.stagger.in > * { animation: rise .6s cubic-bezier(.2,.7,.3,1) both; }
.stagger.in > *:nth-child(1) { animation-delay: 0ms; }
.stagger.in > *:nth-child(2) { animation-delay: 80ms; }
.stagger.in > *:nth-child(3) { animation-delay: 160ms; }
@keyframes rise { to { opacity: 1; transform: none; } }
```

**注意**：`opacity:0` 一定要靠 JS 加 `.in` 触发。如果用户禁用 JS，
`opacity:0` 会让内容永久不可见 —— 所以要么用 `@media (scripting: none)` 兜底，
要么把初始隐藏交给 JS 添加 class（默认可见）。

### letter-spacing 收束

```css
.title { letter-spacing: .3em; animation: tighten .9s ease-out both; }
@keyframes tighten { to { letter-spacing: -.02em; } }
```

### odometer（数字滚动）

```js
function countUp(el, target, dur = 1200) {
  const start = performance.now();
  const from = 0;
  function tick(now) {
    const t = Math.min(1, (now - start) / dur);
    const eased = 1 - Math.pow(1 - t, 3);       // easeOutCubic
    el.textContent = Math.round(from + (target - from) * eased).toLocaleString();
    if (t < 1) requestAnimationFrame(tick);
  }
  requestAnimationFrame(tick);
}
```

用 `IntersectionObserver` 触发，滚到才播。**数字的最终值必须写在 HTML 里**
（`<span data-count="97">97</span>`），这样 JS 失败时用户仍能看到真实数字。

### 背景色过渡

```js
const io = new IntersectionObserver((entries) => {
  entries.forEach(en => {
    document.body.style.backgroundColor = en.isIntersecting
      ? en.target.dataset.bg : 'var(--bg)';
  });
}, { threshold: 0.5 });
```

### SVG 描边

```css
.draw path { stroke-dasharray: 200; stroke-dashoffset: 200; animation: draw 1.2s ease forwards; }
@keyframes draw { to { stroke-dashoffset: 0; } }
```

## 三条铁律

1. **全部纯原生 CSS/JS，零库**。不引 GSAP / Lottie / anime.js —— 单文件、零 CDN 是硬约束。
   （如果用户坚持要库，必须把库**内联**进 `index.html`，并说明体积代价。）
2. **全部尊重 `prefers-reduced-motion`**。
3. **降级不能丢内容**。动效只是修饰，JS 挂了页面必须完整可读。

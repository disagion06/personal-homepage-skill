# 02 · 硬约束与踩坑

这些不是理论，是**真实出过问题之后**总结的。每一条都写了症状，方便你反查。

---

## R1 · 单文件 HTML

`index.html` 一个文件，CSS 与 JS 内嵌。双击能在浏览器打开。

**症状**：用户把 `index.html` 单独发给别人，对方看到的是一片没样式的文字。
**原因**：CSS/JS 引的是外部文件，转发时漏掉了。

例外：图片、视频仍然放 `assets/` 目录（你没法把 12MB 的视频内联进去），
但**必须提醒用户"转发要连 assets 目录一起发"**。

---

## R2 · 不引外部 CDN

字体、图片、JS 库，一律不许走 `http(s)://`。

**症状**：国内打开是白屏，或者等十几秒字体才出现、布局跳一下。
**原因**：Google Fonts / jsDelivr / unpkg 在国内经常不通或极慢。

**替代方案**：字体用系统字体栈。

```css
font-family: Georgia, "Songti SC", "SimSun", serif;          /* 衬线 */
font-family: -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif;  /* 无衬线 */
```

**唯一例外**：`<a href="https://...">` 外链是正常的（那不是资源引用）。

---

## R3 · 图片必须写死静态 src

**症状**：本地双击打开完全正常，发布到 GitHub Pages 后作品图全是裂图。
**原因**：靠 JS 注入 `src`，而 JS 里的路径拼接在你本地对、在服务器上不对，
或者 JS 报错导致根本没执行到注入那一步。

```html
<!-- ✗ 不要这样 -->
<div class="work" data-img="assets/a.jpg"></div>
<script>document.querySelectorAll('[data-img]').forEach(el => { el.innerHTML = '<img src="' + el.dataset.img + '">'; });</script>

<!-- ✓ 要这样 -->
<img src="assets/a.jpg" alt="作品名称">
```

想加灯箱？从卡片的 DOM 里**读**路径，不要往 DOM 里**写**路径。

---

## R4 · 素材文件名必须 ASCII

**症状**：本地正常，发布后部分图片裂图，而且**只在某些浏览器/服务器上裂**。
**原因**：中文名、空格、`&`、括号在 URL 里需要百分号编码，不同环节处理不一致。

**规则**：小写字母、数字、点、下划线、短横线。其他一律改掉。

| 原名 | 改成 |
| --- | --- |
| `工 作照.jpg` | `portrait.jpg` |
| `iPhone 16 & 17 Pro - 1.png` | `iphone-16-17-pro-1.png` |
| `网页.png` / `网页2.png` | `page-01.png` / `page-02.png` |
| `《AI绘梦，众手筑蓝》.mp4` | `video-02.mp4` |

> 注意最后一条：中文标题里夹的 "AI" 别当成有效语义保留成 `ai.mp4`——
> 那比原名更糟，看起来像另一个东西。**残留英文字母少于 3 个就老实改成序号。**

跑 `scripts/preflight.cjs` 会自动给出改名清单，并记录映射，可追溯。

---

## R5 · 视频必须 H.264

**症状**：视频卡片显示出来了，点开播放是黑屏，或者只有声音没画面。
**原因**：iPhone/相机导出的默认是 **HEVC（H.265）** 编码，Chrome / Firefox 不支持。

**检测**（不需要装 ffmpeg）：

```bash
node scripts/preflight.cjs "<素材目录>"
# 会输出：剪辑作品.mp4 → hvc1，浏览器播不了，需转码，169 MB
```

`hvc1` / `hev1` = HEVC，必须转；`avc1` / `avc3` = H.264，可直接用。

**转码**：

```bash
ffmpeg -i "原片.mp4" -c:v libx264 -crf 23 -preset medium -c:a aac -movflags +faststart "assets/video-01.mp4"
```

`-movflags +faststart` 很重要：它把元数据挪到文件头，否则**边下边播**起不来。

---

## R6 · 动效必须尊重 prefers-reduced-motion

**症状**：用户开了系统"减少动态效果"，页面还是狂闪。
**原因**：只写了动效，没写兜底。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .001ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .001ms !important;
  }
}
```

还有一类更隐蔽的：动效元素初始 `opacity: 0`，靠 JS 加 class 才显形。
如果用户禁用了 JS，页面就是一片空白。**兜底要写成"默认可见，JS 才隐藏"**：

```css
.dd-reveal { opacity: 0; }              /* 由 JS 主动添加 */
```

而不是把 `opacity:0` 写死在 HTML 的内联样式里。

---

## R7 · 不许跳过脱敏

**症状**：网站上出现了用户的真实手机号，被爬虫抓走，开始接骚扰电话。
**原因**：AI 生成的页面里带出了用户喂给它的真实联系方式。

这一条是**流程性**的：即使你觉得"这个页面没什么敏感信息"，也跑一次 `redact.cjs scan`。
它零成本，几十毫秒。

## 其他高频坑

### C3 · PSD / AEP 不能直接展示

`<img src="x.psd">` 什么都不会显示。

| 素材 | 处理 |
| --- | --- |
| `.psd` | 导出预览图（PNG/JPG）再入站，图注里标注源工程尺寸，如「源工程 Photoshop (13111×720)」 |
| `.aep` / `.ai` | 网页无法展示，**不要放进 assets**。只在技能标签里佐证（如"After Effects"） |

### C4 · 视频要抽首帧做封面

不抽帧的话，视频未播放时是黑框或白框。

```bash
ffmpeg -y -ss 1 -i "assets/video-01.mp4" -frames:v 1 "assets/video-01-poster.jpg"
```

`-ss 1`（第 1 秒）而不是 `-ss 0`：**首帧常常是纯黑**。

### 横向溢出

**症状**：手机上页面能左右拖动，右边有空白。
**原因**：某个元素比视口宽（长英文串、固定宽度、负 margin、`100vw` 加滚动条）。

排查方法：在浏览器控制台跑

```js
[...document.querySelectorAll('body *')]
  .filter(el => el.getBoundingClientRect().right > document.documentElement.clientWidth + 2)
  .map(el => el.tagName + '.' + el.className)
```

`scripts/check-page.cjs --screenshot` 会自动做这件事并列出嫌疑元素。

### 文字重叠告警经常是误报

自动检测会把**同一行相邻的加粗片段或数字片段**判成重叠。
看到告警先看截图，确认无误就忽略——**不要为了消警告去改好端端的排版**。

### 动效元素是截图盲区

初始 `opacity:0` 的 stagger 元素，截图时还没显形。
验证布局时临时把 `opacity` 强制成 1 再截图（用副本站点，不要改产品文件）。

### GitHub 单文件 100MB 硬限制

超过就直接 push 被拒。50MB 以上会明显拖慢上传。
视频通常要压到 100MB 以内。

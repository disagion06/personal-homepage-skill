# 03 · 设计评审 rubric

用于第 4 阶段。**评审不是写报告，是产出改动清单然后立刻改。**

---

## 六个维度

### 1. 概念（权重最高）

判什么：这个页面的**母题**是否与用户身份强绑定？换个人还能直接用吗？

| 分档 | 判据 |
| --- | --- |
| 9–10 | 母题只有这个身份能成立，换人就崩 |
| 7–8 | 母题贴合，但仍有通用成分 |
| 5–6 | 是常见模板套了点定制 |
| <5 | 纯模板，"作品集模板第 3 号" |

**实例**：「简历 = 一期报纸特刊」—— 因为用户是新媒体运营 + 内容创作，
报纸排版与章节叙事天然对应"出版/编辑"，母题成立。

**改进动作**：如果母题可以被替换（换成"科技感卡片也说得通"），
去找用户身份里**独有**的那个词，把母题重新绑上去。

---

### 2. 哲学一致性

判什么：所有细节是否服从**同一套**视觉语言？有没有哪个元素来自另一套体系？

| 分档 | 判据 |
| --- | --- |
| 9–10 | 每个细节都能追溯到同一套语汇 |
| 7–8 | 大体一致，一两处外来元素 |
| 5–6 | 混搭了两种以上语言 |
| <5 | 拼贴 |

**实例失分**：韦斯·安德森是**方形对称**世界，但头像是**圆形**——
圆形是现代极简/UI 语言，属于外来元素。改成方形报纸肖像照（墨线双框 + 斜体图注）。

**常见外来元素**：圆角卡片出现在硬边排版体系里、霓虹渐变出现在印刷体系里、
谷歌风图标出现在手绘体系里、现代无衬线出现在衬线体系里。

---

### 3. 视觉层级

判什么：标题与正文的**对比是否够**。

| 判据 | 阈值 |
| --- | --- |
| 主标题 vs 正文 | ≥ 2.5 倍字号，否则层级不明显 |
| 区块标题 vs 卡片标题 | 应能一眼分清 |
| 辅助信息（编号、类别） | 不能小到看不见 |

**实例失分**：作品卡里类别字号 12px 与作品名对比不足 2.5 倍，层级塌了。
另外 `FIG.01` 编号只有 10px，**几乎不可见**——小字号要么提到 12px 以上，要么删掉。

---

### 4. 细节执行

判什么：间距是否**成系统**、装饰是否克制。

| 分档 | 判据 |
| --- | --- |
| 9–10 | 所有间距是 4 或 8 的倍数，边框/投影参数统一 |
| 7–8 | 大体有网格，个别手写值 |
| 5–6 | 间距随手写，节奏乱 |
| <5 | 完全无系统 |

**执行方法**：定义 CSS 变量，全局只用这几个。

```css
:root {
  --gap: 8px;
}
/* 用法：calc(var(--gap) * 2) = 16px，calc(var(--gap) * 6) = 48px */
```

**装饰过散**：同一个页面里出现 3 种以上装饰元素（菱形、印章、斜线、圆点、波浪）就是散。
留 1–2 种，重复使用。

---

### 5. 功能性

判什么：有没有冗余内容、入口是否过多、用户能不能一眼找到想看的东西。

- 首屏元素层层叠（标题 + 副标题 + 导语 + 三个按钮 + 四个标签）→ 减到 2 个动作
- 同一信息在多处重复（联系方式既在首屏又在页脚又在浮层）→ 保留 2 处
- 导航项超过 6 个 → 合并

---

### 6. 创新性

判什么：有没有**AI 惯性装饰**。

AI 惯性装饰清单（看到就扣分）：

| 惯用套路 | 为什么扣分 |
| --- | --- |
| 菱形 ◇ 点缀 | 无来源的几何装饰 |
| 红色圆形印章 | 想表达"盖章认证"，但和内容无关 |
| 紫蓝渐变光晕 | 2023 年 AI 生成图标配 |
| 玻璃拟态卡片 | 与任何实体语言都无关 |
| 无意义的浮动粒子 | 纯装饰 |

**替代思路**：装饰应当来自**母题本身的语汇**。
报纸母题就用：栏线、图注、期号、印章式栏目名、首字下沉、油墨噪点——
这些既像报纸，又不是随便贴的几何图形。

---

## 评分之后的动作（重要）

只写分数没有用。输出格式：

```
| 维度 | 分 | 失分原因 | 具体改法 |
| 概念 | 8.5 | ... | ... |
```

然后**按失分最大的三项直接改**，改完再跑一次 `check-page.cjs`。

一个真实的改动清单长这样：

1. 圆形头像 → 方形报纸肖像照（墨线双框 + 斜体图注 `PORTRAIT`）
2. 报头 → 报纸栏题：期号/版本/日期三栏 + 居中刊名 + 栏目表导航
3. 间距统一 8pt 网格
4. 作品卡加报纸图注行：斜体类别居左、`FIG.01-08` 编号居右
5. Hero 编排式加载动效（报眉→刊名→肖像→导语→CTA 依次压印）
6. 编者按首字下沉 + 页脚「Printed in …」印刷信息行

注意每条都是**可执行、可验证**的改动，不是"提升一下质感"这种废话。

---

## 打分不要太客气

一律 8 分以上的评审等于没评审。
真实评审里出现 6.5 / 7 分是正常的，**并且要能被分数所指的问题说服**。

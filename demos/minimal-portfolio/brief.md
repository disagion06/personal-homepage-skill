# Demo 输入：一句话需求

> 这是 `demos/minimal-portfolio/` 的输入示例。真实的对话从这里开始。

## 用户原话

> 帮我做个个人主页，我是做后端的，三年经验。不用放照片，把我做过的东西列出来就行。
> 风格别太花，干净点，能发给我面试的公司看。

## 按 SKILL.md 第 0 阶段确认的三件事

| 问题 | 回答 |
| --- | --- |
| 用途 | 求职，发给面试公司 |
| 内容 | 无现成素材（不放照片），只有经历与项目 |
| 风格 | "干净点" → 推荐 `swiss`（瑞士国际主义：严格网格、无装饰、左对齐） |

## 为什么推荐 swiss 而不是 plain

`plain` 是"简洁现代"，偏通用模板；`swiss` 有明确的排版主张（严格网格 + 单一强调色 + 大量留白），
对"做后端、不花哨、要专业感"的诉求更贴。**推荐风格要说出这个区别，而不是随便挑一个。**

## 阶段 2 产出的结构（确认后）

```
页面标题：张示例 · 后端工程师
色板：bg #FFFFFF / ink #000000 / accent #E30613 / muted #767676

01 hero     —— 姓名 + 一句话定位 + 两个联系方式入口
02 about    —— 三行自我介绍（不写成长文）
03 works    —— 4 个项目，每个：名称 / 角色 / 技术栈 / 一句结果
04 skills   —— 技术栈分组
05 contact  —— 邮箱与 GitHub
```

## 取舍记录

- **不放照片**：用户明确说不用。首屏用大字号排版撑住，不留空白头像占位。
- **不放具体数字成绩**：用户没给，不编造。
- **作品只写 4 个**：宁少勿多，面试官真正会看的是前两个。
- **联系方式保留真实值**：这是求职页面，联系方式是**故意公开**的（见 references/05 的三种情况之一）。
  因此脱敏时用 `--policy mask-high`，不把邮箱打码。
